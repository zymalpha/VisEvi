**每个 A 工具的必备验收：**

1. 定义与接口：目标、输入类型/方向/坐标/尺寸/单位、输出结构、置信度含义、无效输入与拒答行为。
2. 软件正确性：手工可算合成例；正常、空值、边界、方向、尺寸变化、异常输入；期望值不得由被测实现生成。
3. 推理可复现：模型与权重来源/版本/哈希、预处理、设备、阈值、后处理、缓存绑定，逐例保存。
4. 真实图像准确性：与独立人工标注或可信独立参照比较；缺 GT 时只能标“工程已通、准确性未验证”。
5. 可审阅记录：命令、中间量、原图/预测/参照叠加、失败样本、测试结果、限制。

数值门槛不沿用旧文档中未论证的阈值；每个工具的主指标和可接受误差在看到最终测试结果前讨论并写入本文第 6 节。

## 2. 当前阶段：组合功能协议与评估流水线（2026-10-30）

2026-10-30 已按用户确认（接受非商业/仅研究许可、使用 CXAS、A12 用肋骨分割、GPU 4–7）实现全部 A1–A26 接口，详见[项目现状](项目现状.md)。剩余工作的核心是把 A 工具变成可评估的组合功能：

1. 在实现验证未决项登记清楚后，冻结 26 个 `FunctionSpec`，明确每项功能的槽位、A 组合、顺序、输出和拒答。
2. 将 A 输出统一成观察节点，把确定性测量和空间关系作为关系节点，再生成带来源和不确定性的证据声明。

4. 生成确定性的 EvidenceCard，要求消费模型引用声明编号，并由核验器检查方向、数值和适用条件。

## 5. 数据与标注原则

- 不把模型预测当该模型的真值；不把疾病标签当连续测量真值；不从预测 ROI/规则生成同源“人工 GT”。
- 正式测试按患者/检查分组；精确重复排除只是泄漏控制之一，不等于患者独立；同时核实上游模型训练集。
- 开发样本（ChestX-Det `36212.png`、开发 12 例）不进入正式测试。
- 用户已表示有 MIMIC 访问权限，当前先计划按清单小批量准备；各 PhysioNet 衍生项目仍须分别核对授权与 DUA。其他 Kaggle/Stanford AIMI 等受限数据继续按实际需求确认，不绕过访问限制。

## 7. 五类 Gate 的实施边界

应用层路由顺序为：问题向量 → 五个类别 Gate → 类别内功能选择 → FunctionSpec/槽位校验 → A 工具依赖闭包。类别 Gate 不生成医学答案、不输出工具 Claim，也不改变 A 工具参数与适用条件。

当前交付和验收范围：

- 五个独立线性/MLP 头，类别顺序固定为 Q/P/T/S/G；前向 logits 保留编码器与 Gate 梯度。
- 部署独立阈值支持多选/全不选；超预算不截断类别；未配置训练权重时返回 `untrained`。
- `CategoryFunctionGate` 在所选类别内调用规则路由，结果进入 VQA trace；当前单功能 runner 遇到多类别拒绝。唯一类别下的 26 项功能均可进入 VQA 执行。
- 不实现训练损失、优化器或路由标注生成；测试使用 CPU 合成张量和假工具，不能形成语义路由准确率。

训练恢复前需要另定编码器与权重、监督目标、训练/校准/测试划分、多类别真值和阈值验收。采用最终回答 loss 时还必须解决离散选择与外部工具链的梯度或信用分配，不能把当前部署 API 当成现成训练链路。

## 8. 后续研究方案：分层证据程序 → 证据卷宗 → 引用核验作答

本节保留尚待验证的融合、充分性与实验设计，不是当前已实现流程或已冻结验收协议。当前类别路由以第 7 节五个独立 Gate 的决策为准；DS 融合、情境折扣、槽位覆盖求解和定量停止均须单独实现、冻结并评估。实现阶段不得绕过 `FunctionSpec` 直接为单个功能写一次性工具链。

### 8.0 一句话方案

功能不是 26 个独立黑盒，而是**分层的类型化证据程序**：

- Q 层（质量/投照）产出**元证据**，用来折扣其他层证据的可靠度，自身不投票。
- P、T 层产出**对象证据**，每条由 ≥2 个互补通道支撑，按来源去重后用 DS 融合，冲突显式保留。
- G 层在对象证据之上建立空间关系。
- S 层在两次检查的对象证据之间做比较。

运行流程如下：

1. 五类 Gate 选择类别，类内提出已登记功能；类型化槽位抽取是后续扩展。
2. 由 FunctionSpec 展开依赖；最小代价覆盖与充分性停止属于待验证的扩展。
3. 结果编译成带编号的**证据卷宗**（声明表、可选的编号标记图）。
4. 大模型按“每个结论必须引用声明编号”的合同作答。
5. 确定性核验器检查引用、方向和数值。违反合同则重答一次，仍不通过就拒答。

**核心创新点（论文主张）**：

1. **两层证据代数**：对象证据经来源去重做 DS 融合；元证据只作情境折扣，不参与投票。
2. **槽位覆盖式功能规划 + 区间充分性停止**：选择过程可审计、可单独评估，不依赖强化学习。
3. **可寻址卷宗 + 引用核验作答 + 反事实证据依赖评估**：证明大模型确实在用证据，而不是只在形式上收到证据。

### 8.2 证据组织：两层证据代数

**对象证据通道**。需要综合判断的功能优先选两类或更多互补通道；单一通道功能（例如 Q4 投照）必须显式保留来源限制和更宽的无知区间：

| 通道 | 来源 | 擅长 | 典型弱点 |
|---|---|---|---|
| 测量通道 | A9–A14、A12、A13、A19，以及 A5 关键点几何 | 可复算、定量 | 依赖上游 mask 与投照 |
| 专用模型通道 | A8、A26、A1–A4、A5 | 定位精细 | 训练域窄、来源不一 |
| 语义通道 | CheXOne A6/A7/A18 | 覆盖面广 | 未校准、可能幻觉 |
| 外观通道 | A15–A17 | 与模型无关 | 受显示处理影响 |

**元证据**包括 Q1–Q4（吸气、旋转、曝光/穿透、投照），以及工具自身的有效性信号：视野截断、左右肺重叠、解析失败、点在图外、FOV 边界接触。

**融合规则（确定性）**：

1. 每个通道的输出经校准映射 g 转成 mass，Θ={存在, 不存在}，并保留显式无知 m(Θ)。v0 用文献阈值；v1 只在开发集上拟合 g，这是学习组件唯一的合法入口。
2. **情境折扣**：α(通道 | 元证据) 取值 0–1，可连续调节。例如：
   - AP 位时 CTR 通道的 α 下降，因为心影被放大；
   - 吸气不足（膈顶上方后肋 < 9）时 CTR 通道的 α 下降；
   - 旋转指数大时 A19 对称通道的 α 下降；
   - 视野截断时相应测量通道 α = 0。

   折扣只加宽无知，不改变证据方向。所有 α 都有可读理由，进入卷宗的“适用条件块”。
3. **来源去重**：沿溯源图找共享上游的通道（如 A9 心宽与 A12 心宽同源于 A2），合并为一个源，避免把同一证据重复计数当作互证。
4. 跨源用 Dempster 规则组合；冲突 K > 0.6 时改用 Yager 规则（冲突质量归入无知），并把冲突作为显式声明写进卷宗，不平均掉。
5. 每条对象声明输出 [Bel, Pl]、K、参与通道及其 α 与理由、缺失通道。

**示例 P9 心影增大**：

- 通道：CTR（A2 心影 + A12 CXAS 肋骨内缘）、CheXOne A6 心影增大框、A5 心脏轮廓横径与肺轮廓之比。
- 元证据：A24 投照、A25 吸气与旋转。
- 去重：A5 与 A2 来自不同模型，各算一源。
- 预期行为：AP 位或浅吸气时 Bel 收窄，并说明原因；CTR 高而 VLM 判阴时，K 会显出来，卷宗如实列出冲突。

**示例 T1 气管插管**：A26 的 ETT 尖端与隆突给出关系距离；只有存在可信 spacing 时才换算成 cm，否则只报像素并降为不确定。

### 8.3 类别选择后的扩展：槽位覆盖规划与区间充分性停止

1. **功能目录**（版本化）：每个功能声明
   - 命题框架 Θ；
   - 可填的槽位，取自 {finding, location, measurement, device, comparison, condition}；
   - 使用的通道、依赖的元证据、成本（确定性 < 专用模型 < VLM）。
2. **类别与需求解析**：类别启用由五个独立 Gate 负责；类内先沿用规则，未来可扩展类型化需求 JSON（例如 finding=pleural effusion，location=right，需要 condition），经 schema 校验并记录。当前没有通用槽位抽取器，解析错误应独立评估。
3. **规划扩展**：在已选类别和闭集目录内研究最小代价的槽位覆盖，再补上依赖闭包。元证据依赖由规格和协议声明，不能为凑类别数量擅自改写用户意图。
4. **惰性执行**：通道按“预期信息价值 / 成本”排序，先跑廉价的确定性通道，再跑 VLM，与原 LAYER2 规约中的 EIG 一致。满足以下任一条件即停止：
   - **充分**：Pl(h*) − max Pl(h′) > τ；
   - **冲突**：K 超限且没有可仲裁的通道；
   - **不足**：可用通道已耗尽，输出缺失清单。
5. **训练与比较**：五类 Gate 的训练监督方式暂缓，不预设标注监督或最终回答 loss 的优劣；规则路由保留为基线。类别路由、类内功能选择、工具与消费模型的错误分开评估，不预先声明哪种路由更优。

### 8.4 送入大模型：证据卷宗 + 引用合同 + 确定性核验

**卷宗**由确定性渲染生成，同一会话逐字节一致，内容依次为：

1. 适用条件块：元证据，以及它们对哪些通道折扣了多少、为什么。
2. 声明表，格式如：`[C3] 右侧胸腔积液 | 倾向存在 | Bel 0.62, Pl 0.81 | K 0.05 | 通道：CheXOne 框（α 0.8）、A5 右肋膈角变钝（α 1.0） | 位置：标记 ③`。
3. 冲突、缺失与拒答块。
4. 可选的编号标记图：只画空间声明，编号与声明一一对应，采用 Set-of-Mark 式标记。

调研显示 Set-of-Mark 对强闭源模型有帮助，但常使开源模型变差，因此这个图像通道必须做消融，并且可以按消费模型开关。

**作答合同**：每个临床陈述都要引用声明编号；卷宗判为不足时只能回答证据不足；不得与 Bel/Pl 方向相反，除非同时说明冲突；数值必须照抄声明表并带单位。

**核验器**（确定性为主）：

1. 检查编号是否存在；
2. 检查陈述方向与 Bel/Pl 是否一致；
3. 检查数值与单位是否精确一致；
4. 标出没有引用的临床断言（可选用小型 NLI 模型辅助）。

不通过就附带反馈重答一次，仍不通过则输出系统级拒答（AnswerVerdict）。

### 8.5 评估：四层，外加两项创新测试

| 层 | 评什么 | 指标 | 数据（本地或可直接获取） |
|---|---|---|---|
| A 工具 | 单个 A 的预测 | 见[项目现状](项目现状.md)第 2 节及各工具协议 | 对应模型的独立 GT 或确定性复算 |
| B 功能证据 | 每个功能的声明是否正确 | 存在性：AUROC/AUPRC（以 BetP 打分）、ECE；测量：MAE、Bland-Altman；定位：命中率/IoU；**选择性预测**：以区间宽度为拒答分数的风险–覆盖曲线（AURC） | 见下表 |
| C 端到端问答 | 卷宗加大模型的最终答案 | 准确率、覆盖率、引用精确率/召回率、核验通过率 | 外部胸片问答基准作为候选，正式使用前核实来源、许可和与消费/感知模型的训练重叠；另加本地标签模板化问答 |
| D 证据依赖与稳健 | 证据是否真被使用、错误能否被拦截 | 见下 | 合成干预，不需新数据 |

**C 层对照**（同图、同问、每组 ≥3 个消费模型）：

1. 只给图像；
2. 图像加工具原始输出拼接（MedRAX 式）；
3. 加硬门控测量（X-Ragent 式）；
4. 加本框架卷宗，有/无标记图两种。

**D 层两项创新测试**：

1. **互补性矩阵**：每个功能逐一去掉一个通道或一个元证据，记录 B 层指标与校准的变化。这直接检验“工具相互提供互补证据”这一前提，也给每个通道一个可量化的边际贡献。
2. **证据依赖测试（反事实卷宗）**：
   - 翻转某声明方向、删掉关键声明或注入冲突，看答案是否按预期改变或转为拒答，算出证据依从率与恰当拒答率；
   - 另做**感知错误注入**：交换左右、缩小心影 mask、删掉肋骨，统计“被元证据或冲突拦截而拒答”与“静默答错”的比例，即错误传播率。
